# ⚠️ Риски проекта

## 📌 TL;DR

Главные риски текущего состояния: общая БД между сервисами, отсутствие миграций и автотестов, включённый debug-режим, слабая политика паролей, отсутствие CSRF-защиты и известные дефекты (`/profile`, `seed_big_data.py`). По оплате риски описаны только как целевые: реального шлюза и данных карт в системе нет. Персональные данные регулируются законодательством Республики Беларусь.

## 🛡️ Риски безопасности (OWASP Top 10)

| Категория OWASP | Текущее состояние | Рекомендация |
|-----------------|-------------------|--------------|
| A01 Broken Access Control | Роли реализованы, но проверки вынесены в декораторы; нет централизованной политики | Единая матрица прав, тесты на 403 |
| A02 Cryptographic Failures | Пароли хешируются; секреты в `.env`; нет шифрования БД | Менеджер секретов, TLS, аудит ключей |

## 💳 Риски платежей (PCI DSS)

> Оплата в текущем MVP не интегрирована: реальные банковские карты не принимаются, данные карт не хранятся. Раздел описывает риски при внедрении оплаты в Phase 2.

| ID | Риск | Митигация |
|----|------|-----------|
| PCI-001 | Хранение PAN/CVV в таблице `payments` | Никогда не хранить PAN/CVV; использовать токены провайдера |
| PCI-002 | Передача данных карты через собственный gateway | Использовать hosted checkout или iframe провайдера |
| PCI-003 | Недостаточная проверка суммы на бэкенде | Серверный расчёт суммы, сверка с бронью, идемпотентность |
| PCI-004 | Повторное списание при ретрае | Idempotency key и уникальный `transaction_id` |
| PCI-005 | Возврат средства без аудита | Отдельная таблица refunds и журнал действий администратора |

## 🔗 Риски интеграций

| Интеграция | Риск | Митигация |
|------------|------|-----------|
| PostgreSQL | Единственная БД для всех сервисов | Пул соединений, миграции, мониторинг |
| API Gateway ↔ сервисы | Недоступность сервиса блокирует раздел | Health-check, ретраи, circuit breaker |
| CDN | Недоступность Cairo/Bootstrap меняет визуал | Локальные копии, SRI |
| Платёжный шлюз (Phase 2) | Расхождение статусов оплаты и брони | Webhook + сверка статусов |
| Email/SMS (Phase 2) | Недоставка уведомлений | Очередь и повторные попытки |
